# 🎓 زبان‌یار | ZabanYar

اپلیکیشن آموزش زبان انگلیسی با رابط فارسی و راست‌چین — درس‌های تعاملی، فلش‌کارت با مرور فاصله‌دار (SM-2) و پیگیری پیشرفت، همه به‌صورت محلی روی دستگاه کاربر.

**🌐 نسخهٔ زنده:** https://sayeroshan031-ctrl.github.io/learnenglish/

## ✨ امکانات

- **آنبوردینگ مهمان** — در اولین ورود، نام، سطح فعلی (A0 تا C1)، آزمون هدف (آیلتس/تافل) و هدف مطالعهٔ روزانه ثبت می‌شود؛ بدون نیاز به ساخت حساب، داده‌ها روی همان دستگاه می‌ماند.
- **داشبورد** — آمار درس‌ها، پیشرفت و سطح فعلی، همراه با پشتیبان‌گیری و بازیابی JSON از کل داده‌ها.
- **درس‌ها** (`/lessons`) — فهرست درس‌ها بر اساس سطح و بخش، صفحهٔ هر درس با آموزش، مثال و نکته، دکمهٔ «تکمیل درس»، دکمهٔ «تمرین با مربی» (مربی پنهان) و لینک درس بعدی.
- **آزمون هر درس** (`/lessons/:id/quiz`) — پنج سؤال چهارگزینه‌ای برای هر یک از ۱۶۸ درس مسیر صفر (A0) و A1 و A2 و B1 و B2 (۸۴۰ سؤال)، با بازخورد فوری، توضیح پاسخ درست، دکمهٔ خوانش فارسیِ توضیح‌ها با صدای فارسی خود دستگاه (اگر نصب باشد) و ذخیرهٔ بهترین نمره روی دستگاه کاربر.
- **مسیر صفر (A0) و مربی پنهان** — ۸ درس پیش‌مقدماتی برای صفرِ مطلق (الفبا، صداها، اعداد، سلام و معرفی، روزها و ماه‌ها، کلمات بقا) که به A1 وصل می‌شود، و «مربی پنهان» روی همهٔ درس‌ها: مکالمهٔ فارسی اسکریپتی که از دادهٔ خود درس ساخته می‌شود — جملهٔ انگلیسی را پخش می‌کند، از زبان‌آموز تکرار می‌خواهد (میکروفون و تشخیص صدا هرجا موجود بود، وگرنه خودارزیابی)، بازخورد می‌دهد و کاربرد را از متن درس توضیح می‌دهد. بدون هوش مصنوعی و بدون سرور.
- **یادآوری مطالعه و گزارش جمعه** — اعلان روزانه در ساعت دلخواه کاربر (با اجازهٔ مرورگر و Service Worker) و کارت گزارش جمعه روی داشبورد: مدال هفته (طلا/نقره/برنز بر اساس امتیاز فعالیت)، میزان رشد نسبت به هفتهٔ قبل، پیشرفت کلی دوره و یک جملهٔ انگیزشی هفتگی.
- **فلش‌کارت‌ها** (`/flashcards`) — صف مرور روزانه بر اساس الگوریتم **SM-2**؛ چهار درجهٔ خودارزیابی (بلد نیستم/سخت/خوب/آسان) و حالت تمرین آزادِ همهٔ کارت‌ها.
- **تلفظ صوتی** — دکمهٔ 🔊 روی کلمه و جملهٔ مثالِ فلش‌کارت‌ها و کنار مثال‌های هر درس؛ تلفظ با موتور صدای داخلی دستگاه کاربر پخش می‌شود (Web Speech API) — بدون فایل صوتی و بدون سرور.
- **ذخیره‌سازی محلی** — همهٔ داده‌ها در IndexedDB (Dexie) نگهداری می‌شود و آفلاین هم کار می‌کند.

## 🛠️ فناوری‌ها

React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + Dexie (IndexedDB) + Zustand + React Router 6

## 🚀 اجرای محلی

```bash
npm install
npm run dev      # محیط توسعه
npm run build    # ساخت نسخهٔ انتشار (در پوشهٔ dist، همراه با 404.html برای مسیریابی SPA)
```

انتشار روی GitHub Pages با هر Push روی شاخهٔ `main` به‌صورت خودکار انجام می‌شود (`.github/workflows/static.yml`).

## 🗂️ ساختار پروژه

```
src/
  components/   داشبورد، آنبوردینگ، درس‌ها و فلش‌کارت‌ها
  db/           تعریف دیتابیس Dexie و داده‌های اولیه (seed)
  store/        استور Zustand (کاربر فعلی و وضعیت آنبوردینگ)
  utils/        الگوریتم SM-2، پشتیبان‌گیری و برچسب‌های فارسی
  types/        تایپ‌های TypeScript
```

## 📌 وضعیت

برنامه در حال توسعهٔ فعال است؛ مسیر صفر (A0) و سطح‌های A1 و A2 و B1 و B2 کامل: ۱۶۸ درس و ۲۰۷۲ فلش‌کارت واقعی (نسخهٔ محتوای ۹) + کوییز هر درس و محتوا به‌صورت نسخه‌بندی‌شده به‌روز می‌شود. نقشهٔ راه و پیشرفت کار در [Issue #1](https://github.com/sayeroshan031-ctrl/learnenglish/issues/1) پیگیری می‌شود.
